# streamy

A Prototype of an OTT application built using flutter. This App contains a home screen where you can browse the shows and a video player screen which supports swip-up gesture to play next episodes.  

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd streamy
   ```
2. **Install dependencies**
   ```bash
   flutter pub get
   ```
3. **Run the app**
   ```bash
   flutter run
   ```
#### Use the command below to build the APK, then install it to start using the app. 
```bash
# Android APK
flutter build apk
```

#### Dependencies
- `better_player_enhanced` - Enhanced video player
- `flutter_bloc` - State management
- `palette_generator` - Dynamic color theming
